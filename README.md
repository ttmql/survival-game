# 悠然求生 · Wild at Ease

一个零依赖、直接在浏览器里运行的二维程序化沙盒原型。

## 公共网页

游戏地址：https://ttmql.github.io/survival-game/

使用 GitHub Pages 从 `main` 分支的根目录发布。更新并推送 `main` 后，网页会自动重新部署。

当前没有存档功能。重新打开或刷新网页会开始新游戏，背包、建筑、作物、怪物和世界时间不会恢复；网址中的种子仅用于生成地形，不是进度存档。

当前版本可以进入一片随机生成的无限世界，在岩石、草地和海洋之间行走，并挖掘树木、煤炭、草地和岩石，把材料放进装备栏与背包。玩家永远位于画面中心，世界随脚步展开。网页首先显示全屏开始页，可填写任意长度的中英文数字世界种子，留空则随机生成；开局不再自带工具台，而是携带创世卷轴，消耗三个木材即可在背包中生成工具台。右上角有小地图，按 M 可以进入可拖动的探索大地图；开局没有复活点，必须激活复活石碑才能复活。生命归零后所有物品掉落在原地，一天后消失；世界中还会刷新羊、算法鸡、僵尸和野人射手；玩家可以近战或使用木弓战斗，通过食物维持饱食度，并用床跳过夜晚。

## 运行

### Windows EXE 便携版

运行 `npm run build:exe`，或在 PowerShell 中运行 `./packaging/build.ps1`，生成 `dist/荒野方界.exe`。打包使用 Windows 自带的 .NET Framework 编译器，无需下载构建依赖。

EXE 内含当前游戏的 HTML、CSS、JavaScript、图片和音效。双击后解压到 `%LOCALAPPDATA%/WildsGameDesktop/versions/`，使用已安装的 Edge（或 Chrome）打开独立游戏窗口，可离线游玩。运行环境为 Windows 10/11 与 .NET Framework 4.5 以上；无需 Python、Node 或额外服务器。EXE 可单独复制，也支持中文路径。

### 浏览器版

直接双击 `index.html` 即可，不需要安装依赖或启动服务器。

也可以双击 `启动游戏.cmd`，或执行：

```powershell
start .\index.html
```

推荐使用较新的 Chrome、Edge 或 Firefox。游戏使用 Canvas 2D 和普通 JavaScript（没有构建步骤）。

世界种子会写进地址栏，因此刷新页面不会丢失当前世界。也可以手动指定：

```text
index.html?seed=1A2B3C4D
index.html?seed=中文种子English2026
```

地址栏和开始页都接受中文、英文、数字组成的种子，不限制长度；开始页留空时随机生成。

| --- | --- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `Shift` | 疾行 |
| 开始页输入世界种子 | 可选；支持中文、英文、数字，不限制长度；留空随机生成 |
| 开始页「新游戏」 | 进入世界并生成种子对应的地图 |
| `N` | 生成新世界 |
| 长按鼠标左键点击食物 | 食用一个食物；右键仍是丢弃 |
| 点击生物 / 怪物 | 近战攻击；选中木弓时改为朝点击方向射箭 |
| 点击已放置的床 | 白天提示无法睡觉；夜晚等待 3 秒后跳到第二天 06:00 |
| `M` | 打开 / 关闭探索大地图 |
| 侧栏「生成新世界」 | 生成新世界 |
| 鼠标长按资源 | 挖掘两格范围内的树木、煤炭、草地、岩石；空手耗时是正常速度的 4 倍 |
| 单击装备栏中的物品 | 选中/手持该物品；再次单击同一格取消选中 |
| 选中工具后长按资源 | 使用对应工具，按工具倍率挖掘并消耗 1 点耐久 |
| 选中工具台 / 火把 / 石碑 / 复活石碑后左键草地或岩石 | 放置到地面；右键盘位仍然是作为掉落物丢弃 |
| 点击已放置的工具台 | 打开制作界面 |
| 点击工具台配方行 / 物品图标 | 查看该物品说明；点「制作」按钮才进行制作 |
| 点击已放置的石碑 | 查看石碑铭文 |
| 点击已放置的复活石碑 | 激活闪光、点亮一小块区域并加入可用复活点 |
| 长按已放置的工具台 / 火把 / 石碑 / 复活石碑 | 挖掉放置物，并把它作为掉落物留在原地 |
| 大地图内按住拖动 | 平移查看已探索区域 |
| 死亡页面点击「复活」 | 在离死亡位置最近的已激活复活石碑旁满血复活 |
| 点击底部「背包」 | 打开 4 × 8 背包栏 |
| 点击背包里的「退出」 | 关闭背包栏 |
| 单击一个格子，再单击另一个 | 立即交换两个格子的物品（含装备栏与背包的跨栏交换） |
| 单击有物品的格子 | 查看物品说明与耐久 |
| 单击创世卷轴后左键或右键点击地面 | 消耗背包中 3 个木材，并在背包生成工具台；不足时提示「需要三个木材」 |
| 右键装备栏 / 背包中的物品 | 整组丢到角色面前两格，之后可靠近拾取 |

> 选中一个格子后，点击另一个格子仍然是交换；要单纯取消手持，再次单击已选中的格子即可。

## 这一版实现了什么

- **动态音乐**：白天两首舒缓曲目按天数轮换：第一首是马林巴与钟琴主导的卡通风格，第二首是柔和合成器与轻鼓点的现代流行纯音乐；清晨与黄昏改为弦乐合奏，使用慢速运弓、低音提琴和哀伤和声；夜晚是钢琴独奏，加入轻微铃铛与雪橇铃般的圣诞氛围；怪物进入视野时切换到战斗音乐。所有乐曲包含四小节和声、主旋律、副旋律、琶音、铺底与打击乐。
- **受击音效**：羊和算法鸡被攻击时使用 `Music/chicken.wav`；僵尸和野人射手使用更明显、更响的低吼受击声；玩家受伤时播放独立的短促受击音效。
- **动作音效**：挖土、挖矿/岩石、砍树、制作成功、制作失败、放下所有可放置物、激活复活石碑都有各自独立合成的音效。
- **滚轮切换**：游戏进行中滚动鼠标滚轮，会在装备栏的非空格子之间循环切换手持物品，并跳过空格。
- **饱食度保护**：饱食度回满后，在饥饿系统生效时获得 2 个游戏小时的保护期；保护期内不下降，结束后按正常速率消耗。再次吃到满值会重新获得 2 小时。
- **死亡动画**：动物和怪物生命归零后不会瞬间消失，会播放约 0.8 秒的旋转、压扁、淡出和尘土动画，动画结束后才掉落物品并移除。怪物在 06:00 天亮后按每秒 10 点生命值持续受伤，受伤到零后进入死亡动画。
- **熔炼炉取料**：熔炼炉现在同时显示装备栏和背包，煤与食物可以从任一栏点击添加；熔炼产物优先进入装备栏空位，再进入背包。
- **拾取优先装备栏**：获得物品时先寻找装备栏中的可堆叠格和空格，只有装备栏没有空间才放入背包。
- **死亡掉落归属**：动物和怪物被玩家或野人射手的箭杀死时正常掉落；被早晨阳光持续伤害致死的怪物不产生掉落物。
- **固定物前后遮挡**：放置物按上下位置排序绘制，下边的固定物总是绘制在上边固定物的前面，因此下层高物体会遮挡上层物体，不会反过来。
- **物品说明位置**：单击装备栏物品时，说明框出现在装备栏正上方；单击背包物品时，说明框出现在背包面板正上方，并会自动限制在视口内。
- **背包尺寸**：装备栏格子可点击面积约为原来的 2 倍，4 × 8 背包和储物箱格子约为原来的 1.5 倍；桌面端和移动端都重新适配。箭矢绘制在放置物、角色和地面掉落物下方，会被地上的物品遮挡。
- **饱食度**：左上角显示饱食度，初始与上限都是 100。第一天不会下降；从第二天 06:00 起按每个游戏日 50 点的速度下降。饱食度为 100 且生命未满时，按每个游戏小时恢复 30 点生命。
- **生物**：羊和算法鸡在玩家视野外、非水域位置按概率刷新，视野内平均维持 3 只；它们始终随机移动，不会主动追踪玩家，被攻击后会朝远离玩家的方向逃跑一段时间，再恢复随机运动。
- **怪物**：僵尸和野人射手只在 **20:00 之后** 的夜晚、玩家视野外且无火光/石碑光照的非水域位置刷新，视野内平均维持 3 只；刷新后随机移动，只有玩家在视野内看到怪物时，怪物才会进入仇恨并主动靠近攻击。离开玩家视野会恢复随机运动，到早上 06:00 见光死亡。僵尸近战伤害 15；野人射手改为持弓射箭，直线箭矢伤害 25，可躲避。
- **战斗**：点击附近生物可近战攻击；木弓选中后点击任意方向射箭。箭沿直线飞行并受射程限制；玩家和野人射手射出的箭都会被树木、工作台、石碑、床、储物箱、熔炼炉等地面放置物挡住。野人射手的箭如果中途命中动物或其他怪物，也会造成伤害，但不会命中自己。
- **食物与中毒**：长按鼠标左键食用食物，右键仍是丢弃。生羊腿恢复 30 饱食度，50% 概率在 1 个游戏小时内损失 50 生命；算法鸡腿恢复 20，50% 概率在 1 小时内损失 30 生命；僵尸肘子恢复 20，并必定在 1 小时内降低 70% 移动速度。
- **床**：放置后点击，白天提示无法睡觉；夜晚经过 3 秒后跳到下一个 06:00。睡觉期间游戏暂停。
- **开始页与种子**：打开网页先显示全屏开始页，底部只有可选的世界种子输入框和「新游戏」按钮。种子支持中文、英文、数字，长度不设上限；留空时由系统随机生成。开始页隐藏游戏页面本身，点击「新游戏」后才进入游戏。
- **全屏游戏画面**：点击「新游戏」后，游戏画面占据整个网页视口；顶部网站标题、侧栏和页面页脚全部隐藏，只保留游戏 HUD、场景与底部装备栏。画布按保持比例的方式填满可用区域。
- **种子复现**：同一个文本种子会稳定生成同一个世界。短十六进制种子仍保持原有的数值生成方式，其他文本种子使用确定性哈希；种子会原样显示在侧栏并写入地址栏。
- **随机世界**：每个种子都会生成独立的世界；首次打开随机选种。
- **三种地形与比例**：岩石 30%、草地 50%、海洋 20%。
  - 生成每个种子时会采样并校准两条分界线，而不是写死噪声阈值。
  - 测试中随机采样 12 万格，四种子的实际比例与目标误差都小于 0.5 个百分点。
- **迷你视野**：画布内部分辨率为 `480 × 300`，格边长 `20`，所以恰好是 **24 × 15 格**；放大用最近邻采样，保持像素感。
- **玩家居中**：摄像机位置始终为玩家位置减去半个视野，角色不参与滚动。
- **大地图**：世界按 `16 × 16` 区块懒生成，只缓存最近生成的最多 192 个区块；离开后可以按种子重新算出来，没有硬编码地图边界。
- **起始画面**：出生点会优先选在清空的草地，并且开场视野尽量同时出现海洋、岩石和草地。
- **生命、氧气与饱食度**：左上角常驻状态面板，数值加大并分别使用红、蓝、金色显示。生命上限 100、初始 100；氧气上限 10、初始 10；饱食度上限 100、初始 100。进入海洋后切换为「潜行」状态，画面出现水色滤镜、半身水线和气泡。
- **时间与昼夜**：游戏时钟固定在 HUD 正中央。游戏内 24 小时对应现实 5 分钟，从第 1 天 06:00 开始。正午明亮，深夜呈深蓝色暗光，清晨和黄昏使用平滑的暖色光照过渡。
- **地表资源**：草地区域随机生成嵌入地表的树木，岩石区域随机生成嵌入地表的煤炭。它们只作为地表覆盖物存在，不改变脚下的地形，也不会破坏三种地形的比例。
- **背包与装备栏**：底部 8 格装备栏，点击「背包」打开 4 × 8 格背包。普通物品每格最多 64 个，装备每格 1 个；支持单击交换，单击物品即可查看说明。
- **创世卷轴与工具台**：开局没有工具台，装备栏携带无限耐久的创世卷轴。选中卷轴后左键或右键点击，消耗背包中的 3 个木材并在背包生成工具台；木材不足时提示「需要三个木材」。工具台说明为「创造一切吧」。创世卷轴说明末尾提示「拿在手上右键点击」。
- **工具台筛选规则**：配方只要包含至少一种玩家当前持有的材料就会显示；材料不足的配方也会显示，但按钮变灰并标记「材料不足」，缺少的材料用红色显示。只有持有材料种类完全不相干的配方才隐藏。
- **储物箱与熔炼炉**：储物箱提供 4 × 8 格独立存储，可在背包和箱子之间点击转移；熔炼炉先投入小煤块，再点击炼材，一个小煤块烧一个炼材。生羊腿变熟羊腿，算法鸡腿变熟鸡腿，其它物品变奇怪废料。
- **工具台与制作**：放置并点击工具台打开配方界面；点击配方行查看物品说明，点击「制作」获得物品并扣除材料。
- **装备与耐久**：斧头、镐子、铲子、剑都是装备，每格只能放 1 个。耐久条显示在装备栏和背包中：高于 70% 为绿色，30%–70% 为黄色，低于 30% 为红色；耐久归零时装备直接消失。
- **工具效率**：空手或用错工具时速度是正常速度的 1/4（耗时为4倍）；木制工具恢复为正常速度，石制工具为正常速度的 1.5 倍。工具只对对应资源或固定物生效，并在完成一次采集后消耗 1 点耐久。
- **可放置物**：工具台、火把、夸赞斌神的石碑、复活石碑、床、储物箱和熔炼炉属于材料，可以放到草地或岩石地面。短按对应放置物打开制作/铭文/睡眠/储物/熔炼界面，短按复活石碑激活；长按任意放置物可以挖掉回收；火把在夜晚照亮约四分之一屏幕半径，直接显露被夜色遮住的地形。所有交互必须距离玩家不超过两格。
- **放置物阻挡**：所有放置在地面的物品都像树木一样占据格子，玩家、动物和怪物都无法跨过或踩上去；生物移动时会沿障碍边缘滑动，不会穿过树木或放置物。放置时也不能放在玩家脚下。复活石碑激活后，复活会落在石碑旁最近的可站立地面。
- **统一地面阻挡**：所有生物共用 `isGroundBlockedForCreature()` / `mobCanOccupy()` 判定。任何非空地形特征默认阻挡移动，只有明确加入 `PASSABLE_FEATURES` 的嵌入资源（目前是小煤块）可以通过；任何写入 `placedObjects` 的固定物也自动阻挡，多格固定物用 `tiles` 登记全部占用格。以后新增地面固定物或生物时，只要走这两套数据/移动入口，就自动获得统一碰撞规则。
- **路径铁律**：玩家和每个生物都保存最后合法位置；每帧执行 `enforceGroundObstacleInvariant()`，同时检查当前位置和上一位置到当前位置的整段路径。即使未来生物速度很高或位置被直接改写，只要跨过固定物就会被拉回最后合法位置。子弹使用 `projectilePathBlocked()` 做整段路径检测，不会因速度过快跳格穿透。
- **两格交互距离**：床、工作台、火把、石碑、复活石碑、储物箱和熔炼炉都必须在玩家两格范围内才能点击打开或长按回收；距离太远时提示「距离太远，靠近一点」，不会打开界面或开始挖掘。
- **附近小地图**：右上角常驻一张局部小地图，记录玩家周围已经探索的地形，并标出玩家位置和复活点；复活点在视野外时会在边缘显示方向箭头。
- **探索大地图**：按 M 打开独立的世界地图页面。地图只绘制探索过的格子，标记玩家和复活点；已探索区域超出画面时可以按住拖动平移查看。
- **死亡与复活**：生命值降到 0 时，装备栏和背包里的所有物品都会作为掉落物留在死亡位置。点击「复活」会在离死亡位置最近的已激活复活石碑旁满血、满氧复活，掉落的物品需要回到死亡位置拾取。
- **复活石碑**：用 8 个岩石块制作，放置后点击一次开始闪光，在夜晚照亮一小块区域，并加入可用复活点。多块已激活的石碑可以同时生效。
- **鼠标挖掘**：角色两格范围内的树木、煤炭、草地和岩石都可以长按鼠标挖掘。挖掘后先在地面生成掉落物，靠近后才会自动拾取；掉落物会保留一个游戏日（现实约 5 分钟）。
- **树木阻挡**：树木会阻挡角色移动；树木被挖掉后，该位置恢复通行。
- **右键丢弃**：右键装备栏或背包里的任意物品（材料、工具、火把、石碑等），会把该格内的整组物品作为掉落物放在角色面前两格的位置，之后靠近可以再次拾取；工具的当前耐久会随掉落物一起保留。
- **资源外观**：四种材料各有独立的像素图标：小煤块是带冷色反光的黑色矿块，木块是带浅色年轮的堆叠原木，土块是冒草芽的土堆，岩石块是灰色多面石块。背包和地面掉落使用同一套造型语言，地面图标会放大显示并带有材质色光晕。
- **像素细节**：低对比度地形底色、岸边浅水/泡沫、草叶野花、岩石裂缝与碎石、行走动画、新世界淡入。

> 目前只有树木会阻挡通行，工具台、火把、石碑和复活石碑可以走过；角色之间还没有敌人或战斗系统。移动目前只支持键盘，触屏控制尚未加入。

## 生命与氧气（当前规则）

- 生命值上限 `100`，初始 `100`；氧气值上限 `10`，初始 `10`。每次生成新世界都会恢复满值。
- 当脚下地形为海洋时，角色进入 **潜行** 状态。
- 水中：氧气每秒减少 `1` 点。
- 离开水中：氧气每秒恢复 `1` 点，最高恢复到 `10`。
- 氧气为 `0` 时若仍在水中：生命每秒减少 `10` 点。
- 生命值降到 `0` 时触发死亡：装备栏与背包所有格子的物品全部作为掉落物留在死亡位置；页面显示「你死了」，点击「复活」后在复活点满血满氧复活。
- 游戏开始时没有复活点。激活一块或多块复活石碑后，死亡时按距离选择最近的石碑。挖掉石碑会移除该复活点。没有已激活的石碑时，死亡会显示游戏结束。
- 死亡位置会记录在右上角小地图和 M 大地图上，用红色叉号标记，离开地图范围时显示指向死亡点的红色箭头。
- 当前版本生命值在饱食度为 100 时会按每游戏小时 30 点恢复。

## 时间与光照（当前规则）

- 游戏内 **24 小时 = 现实 5 分钟**；现实 1 秒约等于游戏内 4 分 48 秒。
- 进入世界时为 **第 1 天 06:00**；每次生成新世界都会回到第 1 天 06:00。
- 时钟显示在游戏 HUD 的正中央，显示「第几天 + 24 小时制时间 + 时段」。
- 时段划分：
  - `05:00–07:00` 清晨
  - `07:00–17:00` 白天
  - `17:00–20:00` 黄昏
  - `20:00–05:00` 夜晚
- 光照由两层平滑插值叠加而成：夜晚的深蓝色压暗层，以及清晨/黄昏的暖色光层。白天几乎无遮罩，画面最亮；正午到黄昏、深夜到清晨都是连续渐变。

## 地表资源（当前生成规则）

- **树木**：只生成在草地格上，使用低频密度场形成疏密不同的树丛，再逐格随机决定是否长树。
- **煤炭**：只生成在岩石格上，同样通过密度场形成零散的煤脉，再逐格随机落点。
- 两者都是**地表覆盖物**，不是新的地形类型：
  - 树木有树根、草地衔接和投影，看起来长在地里。
  - 煤炭以深色矿块嵌在岩石纹理中，并带有少量灰白反光。
- 生成是种子确定性的：同一个世界种子、同一个坐标，重新加载后树和煤仍然在同一个位置。
- 三种地形的比例只统计底层地形，树木和煤炭不会把世界改成别的地形。
- 树木/煤炭被挖掉后，底层草地/岩石仍保留，并可以继续挖掘一次底层地形。

### 代码接口

- `Wilds.FEATURE`：`NONE / TREE / COAL` 三种地表覆盖物类型。
- `world.featureAt(tileX, tileY)`：查询某个格子的地表覆盖物。
- `world.removeFeatureAt(tileX, tileY)`：移除树木/煤炭，底层地形保持不变。
- `world.isDug(tileX, tileY)` / `world.markDug(...)`：记录草地或岩石是否已经被挖过。
- 渲染器先画全部地形，再单独绘制树木/煤炭，因此树冠可以自然覆盖相邻地表，而不会破坏地形层。

## 背包与挖掘（当前规则）

### 背包结构

- **装备栏**：固定 8 格，常驻在游戏界面底部。
- **背包栏**：4 × 8 = 32 格，初始隐藏；点击「背包」打开，点击「退出」关闭。
- 普通物品每格最多堆叠 **64** 个；消耗耐久的工具每格只能放 **1** 个。
- 单击第一个格子后，再单击另一个格子会立即交换两者内容；空格子和非空格子也可以互换，装备栏和背包栏之间同样可以交换。
- 再次单击已选中的格子会取消选中；单击有物品的格子会显示名称、类型、说明和耐久。空槽不会显示说明。
- 地面掉落入包时，已有同类材料优先合并；没有现成堆叠时优先使用装备栏空位，装备栏满了再进入背包。装备会寻找第一个空格。
- 工具和剑每格只能放 1 个；工具必须位于**装备栏**并被选中，才会作为手持工具生效。背包里的工具也会显示耐久条。
- 游戏开始时装备栏第 1 格自动生成 1 个工具台。生成新世界不会清空背包、装备和制作出的工具，但会清除旧世界地面上的掉落物与已放置的工具台/火把/石碑；如果新世界开始时背包里没有任何工具台，会自动补发 1 个，避免无法制作。
- 工作台/火把/石碑本身是材料，可以堆叠、丢弃、拾取；放置时会消耗 1 个。

- 工具台、火把、石碑、复活石碑被选中后，左键草地或岩石地面即可放置；不能放在海洋、已有资源或已有放置物的格子上。
- 右键同一种物品不会放置，而是按普通物品规则丢到角色面前两格。
- 放置消耗 1 个物品。工具台和石碑短按打开对应界面，空手或错误工具长按约 2.6 秒则挖掉放置物，正确工具基础耗时 0.65 秒，并把对应物品作为掉落物留在原地。
- 复活石碑放下时是暗的。短按后开始脉动闪光，夜间照亮约 2 格范围。每块已激活的石碑都是复活点，挖掉时移除该点。

- 石碑界面显示完整的《夸赞斌神的石碑》铭文，可滚动阅读；碑首、碑身、碑座和刻痕都做了更立体的石材与做旧表现。

### 小地图、世界地图与死亡

- 右上角小地图记录玩家附近已经探索的地形，标出范围内已激活的复活点。最近的复活点超出小地图范围时，边缘会出现指向它的金色箭头。
- 按 `M` 打开完整地图页，只绘制探索过的格子；金色菱形是复活点，白点是玩家。探索面积超过地图时，按住地图拖动查看。
- 玩家移动时会以自身为中心记录探索范围；新世界会清空探索记录并重置复活点。
- 生命归零时，所有装备栏和背包物品会逐格掉落在死亡位置，保留数量和耐久。点击「复活」会在离死亡位置最近的已激活石碑旁恢复满生命、满氧气。

## 地形比例怎么保证

每个种子先生成两块连续的噪声场：

1. **海洋场**：低频、带域扭曲的大陆轮廓。取所有采样点的第 20 百分位作为海岸线，约 20% 为海洋。
2. **岩石场**：频率更高、独立分布的露岩场。只看剩下的陆地采样点，取第 62.5 百分位，使岩石占陆地的 37.5%，也就是全世界的 30%。
3. 其余 50% 是草地。

阈值来自每个种子固定的 32768 个样本，所以同一个种子会复现同一个世界，比例也不会随着行走方向漂移。

出生点不是简单固定到 `(0, 0)`，而是从原点向外扫描“视野构图”：找到同时出现三种地形的视野中心，再吸附到附近一个 `3 × 3` 的纯草地，确保开局不是一整屏单色。

### 死亡原因与封闭区域

- 玩家伤害统一走 `Player.takeDamage(amount, cause)`，仅记录最终致命来源。死亡面板显示淹死、饿死、被具体怪物击败、吃具体食物中毒等原因。
- 怪物攻击自动取生物的 `name`，远程弹体在发射时保存来源名，发射者消失也不会丢失归因；新怪物沿用 melee/ranged 攻击类型即可接入。
- 中毒保存每种食物的来源和剩余伤害，直接伤害/即死食物也自动取物品目录名称。复活、新世界会清空中毒来源与死亡原因。
- 区域判定：四向可连通的内部格必须全部有屋顶，且边缘被阻碍固定物围住；关闭的门可封闭，打开的门不能。非阻碍物不能充当边界。屋顶或边界缺一格即开放；不同封闭房间分别判定。
- `Buildings.RoomIndex` 按屋顶数量有界遍历，并缓存区域及火把；`Game.invalidateRooms()` 在放置、拆除、开关门、新世界时使缓存失效。后续新增改变阻挡状态的功能也必须调用它。
- 怪物与玩家的封闭/开放状态不同时不触发仇恨；状态相同时沿用视野仇恨逻辑（两个不同封闭区域也允许触发）。战斗音乐由真实仇恨触发，不限制昼夜。
- 封闭室内全天保持夜晚无火把的环境暗度，只能由同区域火把或安装在其边界上的火把照亮。普通室外火把不隔着密封墙照亮室内；复活石碑不代替室内火把。

### 浅深水、玻璃与浮木

- 所有水格可用铲子采集一次细沙，水体不消失，仅增加细微沙底挖掘痕迹。深水中以确定性概率生成可通行的嵌入矿物硅石，使用镐采集。

- 玻璃瓶配方：2玻璃+1硅石+1木料；手持玻璃瓶点击两格内水面，消耗1空瓶并得到1装水玻璃瓶，播放装水音效。容量不足时不消耗空瓶。装水玻璃瓶暂只加入灌溉说明。
- 浮木配方：1硅石+1木料；非阻碍物，仅水域可放置。木板砖仅陆地可放。水格有浮木时按可行走支撑处理，不涉水、不耗氧，动物怪物可通过。

- 层级自上而下：屋顶→火把→阻碍物→木板砖/浮木→镶嵌矿物；拆除顺序：阻碍物及其火把→屋顶→木板砖/浮木→矿石（煤/硅石）→地面（含水底细沙）。
- 草地、岩石、水域有不同脚步音效；浅水与深水共用水声。只有实际移动才触发脚步声。
